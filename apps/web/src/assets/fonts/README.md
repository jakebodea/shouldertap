# Tap theme fonts (web preview)

Latin-subset WOFF2 builds of the families the Mac and Windows apps bundle for the sender themes (see `apps/macos/Resources/Fonts/README.md`), used only by the sender's style preview. All are SIL Open Font License 1.1; each family's license is the `OFL-*.txt` beside it. Big Shoulders Display, Geist Mono and Caveat are the variable fonts (so Billboard's weight surge can play here).
